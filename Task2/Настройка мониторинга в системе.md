# Мотивация
- Превентивное решение проблем клиентов, а не на основе жалоб
- Возможность мониторинга как инфраструктуры так и бизнес-метрик - это возможность улучшать показатели качества сервиса
- Определение необходимости увеличения ресурсов на основе измеримых показателей
- Возможность масштабирования без страха не уследить за разрастающейся инфраструктурой

# Выбор подхода к мониторингу

USE - Utilization, Saturation, Error
RED - Request, Error, Duration
4GS - Duration, Traffic, Error, Saturation

| Элемент инфраструктуры      | Мониторинг | На что смотрим                                                                                                        |
| --------------------------- | ---------- | --------------------------------------------------------------------------------------------------------------------- |
| Очередь                     | USE        | U - время самого долгого сообщения в очереди<br>S - кол-во сообщений в очереди<br>E - кол-во недоставленных сообщений |
| Приложение (MES, CRM, Shop) | 4GS        | D - длительность запроса<br>T - код запроса 200<br>E - код запроса 500<br>S - CPU%<br>                                |
| БД                          | 4GS        | D - длительность запроса<br>T - запрос успешен<br>E - запрос завершился ошибкой<br>S - disc IO                        |
| S3 Storage                  | 4GS        | D - длительность запроса<br>T - запрос успешен<br>E - запрос завершился ошибкой<br>S - disc IO                        |
|                             |            |                                                                                                                       |
